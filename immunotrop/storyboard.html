Таймлайн

Как собрать ролик

1. Озвучка

Записать текст по сценам (14 файлов). Реальная длина каждого файла задаёт длительность сцены.

2. Ключевые кадры

Для каждой сцены 1–3 стоп-кадра: главный промт стиля плюс промт сцены. Отбираем по единству цвета.

3. Анимация

Image-to-video, клипы по 5–10 с, движение камеры берём из строки «Камера». Длинные сцены собираем из 2–3 клипов.

4. Монтаж

Клипы под голос, белые подписи по таймкодам, переходы как в строке «Переход», музыка и звуки.
